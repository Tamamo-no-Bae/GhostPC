Enemy Zoo test map - source
===========================

The source of the Enemy Zoo test map (9_1_1a_Enemy_Zoo), the level GhostPC adds at the end of the
mission list. The map is generated by a Python script and compiled with the community OpenNOD SDK:

  https://github.com/aknavj/nodsdk-scghost

The compiled level is already part of this patch (Levels\9_1_1a_Enemy_Zoo.*); this folder is only
needed to change or rebuild it.


FILES
-----
  make_zoo_map.py        generates zoo.map: rooms, walls, lights, units and props, and the level's
                         side files (out_*). All layout values are at the top of the script.
  zoo.map                the generated map (Radiant/Quake-style .map with NOD template entities)
  compile_zoo.bat        compiles zoo.map with the SDK into out\9_1_1a_Enemy_Zoo.nil/.nsd/.npd
  install_zoo.py         installs the compiled level and its side files into the game folder: sky and
                         world bounds patched into the .nil, track frames (sniper and cut Goliath
                         bosses) written into the .nsd, plus the files below
  out_levelscript.gpc    GhostPC level script (start position, boss triggers, sunken_los, fly_path)
  out_effects.nlfx       the effects the level loads
  out_frames.txt         boss track frames for install_zoo.py
  out_mutalisk_path.nad  the Mutalisk's flight path (installed as 3D\Anims\zoo_mutaliskFlyAround.nad)
  zoo_goliath_222c.nms   the cut Goliath boss's motion set (installed to 3D\Motions)
  make_menu_images.py    makes the mission-select pictures (UI\Materials\911a_MenuImage*.dds) from
                         a screenshot (needs Pillow)
  zoo_overview.py        called by make_zoo_map.py: writes ZOO_OVERVIEW.md (every area, door, unit,
                         pickup and boss trigger in world coordinates) and zoo_overview.png / .svg
                         (a top-down plan of the same)
  ZOO_OVERVIEW.md, zoo_overview.png, zoo_overview.svg
                         that overview, for the current map
  notdump.py, modifiers.txt
                         reader for Misc\Templates\Global.not (template names, model sizes, effects)


REBUILDING
----------
Requirements: Python 3, and the OpenNOD SDK's MAPtoNIL / MAPtoNSD / MAPtoNPD tools.

This folder is expected inside the prototype's folder (next to Ghost.exe), as the patch installs
it; otherwise set GHOST_GAME_DIR to that folder.

  1. python make_zoo_map.py          (only after changing the script; zoo.map is included)
  2. compile_zoo.bat                 (set NOD_SDK_DIR to the SDK's folder, or copy its tools
                                      into mapsrc\sdk)
  3. python install_zoo.py           (installs into the game folder's Levels, 3D\Anims and
                                      3D\Motions)

The level needs GhostPC: its level script, the restored boss AIs and several unit fixes are part of
GhostPC.exe, not of the map.
