Protoss Arena - source
======================

The source of the Protoss Arena (8_1_1a_Protoss_Arena), GhostPC's competitive map (Multiplayer ->
Competitive -> 2 Players). Like the Enemy Zoo it is generated by a Python script and compiled with the
community OpenNOD SDK:

  https://github.com/aknavj/nodsdk-scghost

The compiled level is already part of this patch (Levels\8_1_1a_Protoss_Arena.*); this folder is only
needed to change or rebuild it. It uses the Enemy Zoo's install_zoo.py and notdump.py (one folder up).


FILES
-----
  make_arena_map.py      generates arena.map: a symmetric Protoss arena (four pillars, side rooms north
                         and south, two side corridors into a large corridor and the room west of it),
                         pickups, lights, waypoints, and the level script with the two starts and the
                         competitive respawn points. All layout values are at the top of the script; it
                         checks that every brush and pickup has its mirror image.
  arena.map              the generated map (Radiant/Quake-style .map with NOD template entities)
  compile_arena.bat      compiles arena.map with the SDK into out\8_1_1a_Protoss_Arena.nil/.nsd/.npd
                         (the SDK in ..\sdk, or set NOD_SDK_DIR to the folder with MAPtoNIL.exe)
  install_arena.py       installs the compiled level into the game folder (world bounds and the .nsd's
                         environment fields patched as for the Enemy Zoo) with the files below
  out_levelscript.gpc    GhostPC level script: player_start, player2_start and respawn points
  out_effects.nlfx       the effects the level loads
  arena_overview.png     the layout seen from above
  menu_shot.png          the screenshot the mission-select pictures (UI\Materials\811a_MenuImage*.dds)
                         were made from: ..\make_menu_images.py --name 811a_MenuImage menu_shot.png
                         400 160 1600 760


REBUILDING
----------
  python make_arena_map.py
  compile_arena.bat
  python install_arena.py
